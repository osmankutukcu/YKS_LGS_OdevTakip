========================================================================
     YKS - LGS ODEV TAKIP YONETICISI v2 - WINDOWS HIZLI BASLANGIC
========================================================================

Bu klasör, YKS-LGS Ödev Takip v2 sisteminin Windows bilgisayarlarda 
çalışması için özel olarak hazırlanmıştır.

------------------------------------------------------------------------
1. ILK KURULUM (TEK TIKLA OTOMATIK)
------------------------------------------------------------------------
Klasör içindeki "Windows_Kurulum_ve_Baslat.bat" dosyasina cift tiklayin.

Bu sihirbaz:
  1. Bilgisayarinizda Python yoksa otomatik olarak resmi sunucudan indirip kurar.
  2. Gerekli tum bilesenleri (PyQt6, Pandas, Excel destegi vb.) hazirlar.
  3. Masaustunuze "YKS-LGS Odev Takip" adinda resimli bir kisayol olusturur.
  4. Uygulamayi baslatir.

------------------------------------------------------------------------
2. DAHA SONRAKI CALISTIRMALAR
------------------------------------------------------------------------
- Masaustunuzdeki "YKS-LGS Odev Takip" kisayoluna cift tiklayabilir,
- Veya klasor icindeki "Baslat_Windows.bat" dosyasina cift tiklayabilirsiniz.

------------------------------------------------------------------------
3. TEK PARCA KURULUM (.EXE / SETUP) DOSYASI URETMEK
------------------------------------------------------------------------
Uygulamayi baska Windows bilgisayarlara tasimak veya hicbir Python kurulumu
olmayan cihazlarda dogrudan calistirmak isterseniz:
  1. Klasor icindeki "Windows_EXE_Uret.bat" dosyasina cift tiklayin.
     (Onceden kurulum bat dosyasini calistirmis olmaniza gerek YOKTUR; 
      bu script tum derleme ortamini, PyQt6 ve gereksinimleri sifirdan
      tamamen otomatik olarak hazirlar).
  2. Islem bittiginde:
     - dist\OdevTakip_v2\OdevTakip_v2.exe (Dogrudan calisabilir EXE klasoru)
     - dist\OdevTakip_v2_Kurulum.exe (Kurulum Setup programi)
     hazir olacaktir.
  3. Bu olusan exe dosyasini istediginiz baska bir Windows bilgisayara
     goturup hicbir kurulum gerektirmeden cift tiklayarak calistirabilirsiniz.

Iyi calismalar dileriz!
